# Week 0: Python Foundations Review

## Revised Bootcamp Structure

### Week 0 — Python Review (New)

Focus on building confidence with the Python concepts that caused the most friction during the Contact Manager project.

Topics:

1. Functions

   * Parameters
   * Arguments
   * Return values
   * Scope

2. Control Flow

   * `if` / `elif` / `else`
   * Boolean expressions
   * Short-circuit logic

3. Loops

   * `for`
   * `while`
   * Nested loops
   * `break`
   * `continue`

4. Return Statements

   * Returning early
   * Returning after a loop
   * Search patterns
   * Count patterns
   * Validation patterns

5. Lists and Dictionaries

   * Iteration
   * Searching
   * Updating
   * Adding
   * Removing

6. Small Practice Problems

   * Search
   * Count
   * Validation
   * Simple menu programs

Only after these feel natural will we resume the original bootcamp.
